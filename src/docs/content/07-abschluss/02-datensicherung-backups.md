# Datensicherung & Backups

Zur Vermeidung von Datenverlusten erstellt QuixPOS automatische und manuelle Backups aller lokalen Datenbanken, Einstellungen und Belegjournale.

![Backup-Verwaltung](/docs/images/dialog-backups.avif)

## Backup-Funktionen

- **Automatisches Tages-Backup**: Bei jedem Z-Bon wird automatisch ein verschlüsseltes Backup archiviert.
- **Manuelle Sicherung**: Erstelle jederzeit mit einem Klick einen vollständigen Export.
- **Wiederherstellung**: Im Falle eines Gerätetauschs kann ein bestehendes Backup einfach eingespielt werden.
