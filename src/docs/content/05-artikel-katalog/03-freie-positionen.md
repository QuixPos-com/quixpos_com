# Freie Positionen & Sonderverkäufe

Für Spontankäufe, Dienstleistungen oder Artikel, die noch nicht im Sortiment gepflegt sind, können freie Positionen angelegt werden.

![Dialog zur Erfassung freier Positionen](/docs/images/dialog-custom-line.avif)

## Freie Position erfassen

1. Klicke oder tippe im Kassenmenü auf **Freie Position**.
2. Gib die Artikelbezeichnung ein (z.B. *„Änderungsschneiderei"* oder *„Sonderposten"*).
3. Trage den Brutto-Preis und den passenden Steuersatz (19 %, 7 %, 0 %) ein.
4. Klicke auf **Hinzufügen**.
