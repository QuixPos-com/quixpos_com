# Downloads & GitHub Releases

Hier findest du alle aktuellen Installationspakete, Release-Builds und Direktdownloads für QuixPOS und QuixPOS2JTL.

| Paket | Plattform | Beschreibung | Download-Link |

## Systemanforderungen

- **Android Kasse**: Android 11+ , 9" oder mehr empfohlen
- **Web-Anwendung**: Google Chrome empfohlen
- **QuixPOS2JTL Sync Server**: Windows 10 / 11 / Windows Server 2016+ oder Linux
- **Drucker**: ESC/POS-kompatible Bon-Drucker
- **Kartenterminals**: SumUp Air, Solo, Lite oder OPI-kompatible Terminals
